# Video description (submission form)

TraceForm fills in forms from messy documents (emails, letters, Word files, photos and scans) using Meta's Muse Spark model (muse-spark-1.3, through the Meta Model API's Responses API with schema-constrained JSON), and makes every answer accountable. In this 3-minute demo, a live run extracts nine grant-intake fields, each tied to a verbatim quote that code, not the model, verifies in the source; clicking a field highlights the exact sentence. When the application says $48,000 and a later email says $54,000, TraceForm shows both and the person chooses. A field no document mentions stays blank instead of being guessed. On the clearly labeled sample data (not live AI), a planted fake quote is caught and repaired in Meta's one-shot repair pass; in live tests, 3 of 3 fake citations were caught. A photographed note is read by Muse Spark vision and can be compared with the original. A separate Meta call gives an advisory second opinion, a person approves every answer, and the reviewed values export to CSV or JSON. The model wait is shown sped up 4× and labeled; everything else is real time on the live app.
